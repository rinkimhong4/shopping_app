A comprehensive Flutter-based shopping application offering a seamless e-commerce experience with modern features and multi-platform support.

## Features

### User Authentication

- Secure user login and signup functionality
- OTP verification for enhanced account security
- Supabase
- Comprehensive profile management with customizable settings

### Shopping Experience

- Interactive home dashboard for easy navigation
- Advanced search functionality to find products quickly
- Shopping bag/cart management with add, remove, and update options
- Immersive 3D product visualization for detailed product views

### User Profile & Settings

- Detailed profile screen with user information
- Card management for saved payment methods
- General profile settings for personalization
- Additional profile settings for advanced configurations
- Secure logout functionality

### Notifications

- Real-time notifications system for order updates and promotions

### Payment Integration

- Support for multiple payment gateways including:
  - ABA Bank
  - ACLEDA Bank
  - American Express
  - MasterCard SecureCode
  - PayPal
  - Visa
  - Wing Bank
- Secure and encrypted payment processing

### Delivery Services

- Car delivery options for flexible shipping
- Delivery tracking with real-time updates
- Fast and reliable delivery services

### Social & Support

- Social media integration (Facebook, Instagram, Telegram)
- Customer service chat support
- Email and phone contact options

### Multi-Platform Support

- Native Android application
- Native iOS application
- Web application for browser access
- Desktop support for Linux, macOS, and Windows
